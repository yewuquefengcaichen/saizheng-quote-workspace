# v0.9.0 稳定版发布说明

## 版本信息

- 版本标签：`v0.9.0`
- 稳定分支：`stable/v0.9-quote-workbench`
- 基线提交：`ffffe34`
- 发布时间：`2026-04-15`

---

## 版本定位

`v0.9.0` 是当前报价工作台的 **稳定回退版本**。

它代表的是：

> **可以继续工作 + 可以随时回退 + 作为后续 V2 升级的安全基线**

---

## 已具备的能力

- 商品库导入
- 报价单上传与解析
- 候选商品匹配
- 人工确认 / 无匹配 / 问老板收口
- 批量调价与导出
- 模板中心、历史记录、同义词管理
- 报价台左右分栏工作流

---

## 为什么要冻结这个版本

因为后续升级会引入：

- PostgreSQL
- 图片归档
- 图搜图
- 新的同步链路
- 更大规模的数据层改造

所以必须先保留一个稳定、可工作的基线版本，避免升级过程中没有退路。

---


## 后续升级方向

- Flask 工作台继续可用
- V2 架构逐步把商品、图片、规则、历史迁到 PostgreSQL
- 未来再继续升级到 React + TypeScript + Redis + 更完整的任务系统
