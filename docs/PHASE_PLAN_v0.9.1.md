## 4. 风险与应对

- 风险：模板数据结构与历史 JSON 不一致
- 应对：先保留 JSON 双写，必要时做字段兜底映射，不硬切单链路

- 风险：上线前回归中发现图搜图链路、缓存或向量状态不一致
- 应对：以 `3300 / 3300`、`pending_assets = 0` 为冻结事实，只做增量补跑与问题定位，不再把全量生成作为阻塞项

- 风险：回归范围扩散
- 应对：先保核心路径（报价台 / 词库 / 历史 / 图搜图），非核心问题下个迭代处理
