# Home Workspace Override

Use this file before building or revising the home screen.

## Mission

The home view should answer three questions in under five seconds:

1. What can this system produce
2. What is my next action
3. Where is the current job state

## Home Role

This is not a marketing landing page. It is the start of a quotation cockpit.

## Structure

### A. Top Shell

- Glass top bar with product identity, build state, and one compact status cluster
- No cluttered icon row

### B. Compact Hero

- Keep the hero premium and calm, but reduce its visual dominance once the user has data
- Left side: one sentence on system value
- Right side: today summary, current job status, or quick stats

### C. Quick Action Rail

Show only the core starting moves:

- import product base
- import quote or OCR image
- browse export templates

These must look like equal-quality product actions, not random utility buttons.

### D. Template Center

The template center remains a key differentiator and should stay on the home screen.

Required feel:

- browse-first
- premium preview cards
- clear separation between system templates and mall templates
- visible "what this template becomes next" context

### E. Current Job Strip

When the user already uploaded data, show a compact strip with:

- products loaded
- quote source
- unresolved item count
- last export state

This should replace empty ceremonial space.

## Home Visual Rules

- hero height should be reduced compared with the current version
- use more restraint in blue gradients
- keep copy shorter and more product-like
- quick actions should read as a command deck, not large marketing buttons

## Remove Or Tone Down

- oversized first-screen copy after data exists
- repeated large CTA buttons that say similar things
- any section that feels like a brochure instead of a workspace

## Success Criteria

- the page looks premium at first glance
- the user can immediately start work
- the template center feels like a real product feature, not a decorative block
